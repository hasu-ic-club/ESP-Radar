# Task 01: Radar Initialization Demo

This project is the first in a series of projects designed to help developers understand the complete process of controlling TI mmWave radar devices using an ESP32 and the mmWaveLink SDK.

## Overview

The project demonstrates how to initialize, configure, and acquire high-speed radar data from a TI mmWave radar device using the ESP32-P4.

The ESP32-P4 communicates with the radar over **SPI** to perform device initialization and radar configuration. Once configured, radar data is streamed through the **MIPI CSI interface**, transferred into a buffer in **PSRAM**, and eventually written to an **SD card** for storage.

## Key Features

- **Radar Initialization and Configuration:** Initialize and configure TI mmWave radar devices through the SPI interface using the mmWaveLink library.
- **High-Speed Data Acquisition:** Receive raw radar data through the ESP32-P4's MIPI CSI interface.
- **PSRAM Buffering:** Store incoming radar data in PSRAM buffers to accommodate high-throughput data acquisition.
- **SD Card Storage:** Save acquired radar data as binary files to an SD card for offline analysis.

## What You Can Learn

This project provides a practical starting point for developers who want to work with TI mmWave radar devices using ESP32.

By exploring the source code, you can:

- Understand how to integrate and use the mmWaveLink library on the ESP32 platform.
- Learn the radar initialization and configuration sequence.
- Modify radar configuration parameters directly in the source code and experiment with different radar settings.
- Understand how to receive high-speed radar data through the MIPI CSI interface.
- Obtain raw radar acquisition files from the SD card for further inspection, signal processing, and analysis.

The binary files generated by this project can be used with external tools such as MATLAB or Python to inspect and process the acquired radar data.

## Hardware Requirements
- ESP32P4 Radar Development Board (w/ TI xWR 2243 radar)
- SD Card

## Build and Run

You can use `idf.py menuconfig` to configure the hardware macro definitions for your custom board. There is a menu named `mmWave Radar Subsystem Configuration` to do this.

Use the standard procedure of building a ESP32 program to build the project.

```sh
idf.py build flash monitor
```

Before you run the program on your hardware, please insert the SD card in the slot. The program will check the SD card present or not before all demonstrations.
